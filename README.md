# حزمة مراجعة سياسات LXHAZZAA
هذه الحزمة تحتوي مسودة نصوص السياسة الجديدة؛ لم تُرفع إلى قاعدة البيانات ولم تُنشر على الموقع.

الخطوات الآمنة:
1. مراجعة النصوص قانونياً والتحقق من الحقوق والتراخيص والخصوصية.
2. إعداد صفحة عامة لعرض النسخ المعتمدة، وإضافة رابطها في تذييل كل منصة.
3. تعديل واجهة `public/assets/legal.js` بحيث يظهر الملخص ومربعا الموافقة افتراضياً، وتظهر التفاصيل فقط عند الضغط على «المزيد».
4. إنشاء إصدار جديد من السياسات في Supabase بدلاً من استبدال سجل 1.0، ثم اختبار استرجاع الإصدار وتسجيل الموافقة على حساب تجريبي.
5. قبل إطلاق رفع الوثائق: إنشاء نظام رفع آمن، إدارة الأدوار والتراخيص، أختام المستخدمين، سجل المراجعة والاعتراضات، والتصدير المتوافق مع الحقوق.
6. اختبار الموقع على بيئة تجريبية قبل النشر النهائي.

تنبيه: نظام رفع الوثائق والأختام وتصدير PDF ليس منفذاً حالياً؛ لا يجوز تقديم المسودة على أنها ميزة عاملة.
