❔ إعداد مرجع المشروع
مدير المشروع
  1. جهّز تصدير CSV أو TSV مصرحًا باستخدامه، بعناوين واحدة: kitId وhaplogroup وsnpVerified وأسماء ماركرات STR. احتفظ بكل صف عينة مستقلًا. لا ترفع صفحة HTML أو جدولًا متعدد الرؤوس أو XLSX مباشرة؛ صدّر ورقة واحدة إلى CSV.
  2. افتح «إدارة مراجع المقارنة»، وأكمل اسم المرجع ورابطه وإصداره وتاريخه ثم اختر ملف المشروع. تُجهز بيانات المرجع تلقائيًا دون كتابة JSON.
  3. ضع snpVerified=true فقط للنتائج التي دققت تأكيد SNP لها؛ STR أو وصف Big Y دون دليل ليس تحققًا مستقلًا. الصفوف الأخرى لا تُستخدم كمرجع مؤكد.
  4. اختر عينة واحدة برقمها للتنبؤ. رفع الجدول هنا يجهّز مرجع المقارنة؛ تحليل كل أفراد المشروع وحفظهم ونشرهم دفعة واحدة غير متاح بعد.
