# مراجعة الرفع والأرشفة — 2026-11-05

## الحالة الفعلية

المتنبئ مختبر محلي للمالك والمدير؛ لا يرفع البيانات إلى الخادم ولا يحفظها في قاعدة البيانات ولا ينشر العينات في المشجرة. إصلاح CSV وإضافة المساعدة لا يغيّران هذه الحقيقة. لا توجد بعد واجهة استقبال إنتاجية أو معاملة قاعدة بيانات تمنع التكرار بين الحسابات والملفات. لا يجوز وصف المسار بأنه جاهز لاستقبال الجمهور.

## ما تم اختباره وإصلاحه

- قراءة CSV/TSV قياسي واحد العناوين؛ دعم BOM وCRLF والخلايا المقتبسة والخانات الفارغة.
- استيراد مرجع مشروع مع بيانات مصدر JSON يعبئها المدير؛ قبول مراجع SNP وفق تصريح المستورد لا يثبت صحة التصريح.
- اختيار صف الفرد برقم kitId المطابق تمامًا؛ رفض اختيار عدة أفراد دون رقم، والأعمدة غير المتسقة، والمعرفات المتكررة داخل الملف، والماركرات المكررة أو غير المدعومة.
- قراءة ملف الفرد بصيغة Marker,Value أو صف أسماء ماركرات وصف قيم أو JSON؛ لا تُخمن مواضع أعمدة صفحة ويب كاملة.
- مساعدة قابلة للفتح بعلامة استفهام تشرح ملفات الفرد والمشروع والنسخ وحدود الدعم.
- الاختبارات آلية ببيانات اصطناعية. ليست قياسًا لدقة التنبؤ؛ لم يقدم ملف أصلي مصرح به من مدير مشروع لاختبار اختلافات تصدير المواقع.

## عقد الأرشفة المطلوب قبل فتح الاستقبال

هذا تصميم مطلوب، وليس خدمة منفذة أو منشورة.

1. يتحقق الخادم من جلسة الحساب وصلاحية صاحب العينة أو تفويض مدير المشروع والموافقة المطلوبة على المعالجة والنشر كل على حدة. لا يكفي أن يحتوي CSV رقمًا أو snpVerified=true.
2. تحفظ نسخة أصلية في مخزن خاص خارج public وGitHub، مع بصمة SHA-256 يحسبها الخادم، وحجم الملف وصيغته ووقت الاستلام وهوية الرافع ومصدره ونسخة الموافقة. يحفظ اسم الملف كبيانات ولا يستخدم مسارًا للتخزين.
3. لكل عينة UUID داخلي ثابت. يسجل المصدر ورقمه الأصلي كما ورد، والرقم المطبع للبحث؛ لا يُستبدل رقم المصدر برقم يختاره الرافع. الأرقام محفوظة كنص للحفاظ على الأصفار والبادئات.
4. جدول aliases منفصل: source + normalized_external_id قيد UNIQUE على مستوى قاعدة البيانات؛ رقم FTDNA ورقم YFull ليسا مساحة أرقام واحدة. الربط بينهما يتطلب دليلًا ومراجعة، لا تطابق الأرقام وحده. قيد UNIQUE ينفذ داخل المعاملة ليمنع سباق رفعين متزامنين.
5. import_jobs وimport_rows يسجلان كل صف ونتيجته وسبب رفضه أو تعليقه، مع مفتاح إعادة محاولة مرتبط بالحساب والطلب؛ إعادة إرسال الطلب لا تنشئ عينات أو توقعات جديدة. إعادة رفع ملف من مدير آخر لا تمنحه صلاحيات على عينة موجودة.
6. sample_versions يحفظ القيم الأصلية والمطبعة وإصدار القارئ ومصدر كل قيمة؛ التحديث يصدر نسخة جديدة ولا يمحو السابقة. تعارض رقم قائم مع قيم مختلفة يعلق للمراجعة، ولا يكتب فوق السجل المعتمد.
7. predictions يحفظ إصدار المحرك ونسخة المرجع والمدخلات ومواضع المقارنة والمسار المرشح وحدود الدعم. النتيجة تظل prediction ولا تتحول إلى SNP مؤكد. النتيجة غير المحسومة تحفظ للمراجعة دون اختلاق فرع نهائي.
8. audit_events يحفظ فعل الرفع والتحقق والربط وتغيير العلم والتحور والصلاحيات، مع المنفذ والسبب والوقت. لا تُنشر السجلات أو البريد أو الملفات الخام. أرشفة الملفات والصلاحيات ومدة الاحتفاظ تحتاج سياسة محددة؛ لا تُعامل كاحتفاظ أبدي تلقائي.
9. النشر حدث لاحق مستقل: موافقة نشر وصلاحية ودليل هوية ومراجعة التعارضات ثم سجل مشجرة واحد مرتبط بـUUID العينة، يحمل وسم التنبؤ. لا تنشر كل صف لمجرد نجاح التحليل.

## كشف التكرار والاشتباه

| الحالة | التصرف المطلوب |
| --- | --- |
| نفس المصدر ونفس الرقم ونفس المحتوى | ربط بالسجل الموجود وتسجيل محاولة الاستيراد دون إنشاء عينة ثانية |
| نفس المصدر ونفس الرقم وقيم مختلفة | تعليق النسخة الجديدة، مقارنة المصدر والدليل، دون استبدال السابقة |
| نفس المحتوى تحت رقم آخر | إشارة اشتباه خاصة ومراجعة؛ ليست إثبات تزوير أو سبب دمج آلي |
| تشابه جزئي في STR | لا يثبت وحدة الشخص؛ لا يُستخدم كحظر قطعي أو إثبات احتيال |
| رقم مختلف بين FTDNA وYFull | مقبول عند تقديم دليل ربط؛ يحفظ الرقمان كـaliases لعينة واحدة |
| رقم مكتوب في CSV دون إثبات مصدر | هوية غير متحققة؛ لا نشر تلقائي ولا نقل صلاحيات |
| ملف معدل أو رقم يختلف عن مستند مصدر موثوق | حجر للمراجعة وإظهار السبب لصاحب الطلب دون كشف بيانات عينات الآخرين |

تطابق البصمة يثبت تطابق الملف فقط. تطابق الملف مع نسخة موثوقة يتطلب الحصول على تلك النسخة بطريقة مصرح بها. شكل رقم العينة والرابط المكتوب والراية ليست إثبات ملكية. ملفات CSV قابلة للتعديل؛ لا يمكن ضمان كشف كل تغيير للرقم اعتمادًا عليها وحدها. لا يجوز اتهام رافع بالتلاعب من تشابه STR وحده.

## اختبارات قبول ما زالت مطلوبة

- رفع فرد ومشروع عبر الخادم، إعادة المحاولة وانقطاع الشبكة، ورفعان متزامنان لنفس الرقم.
- اختبار تفويض مدير المشروع وعدم وصوله لعينات خارج نطاقه، وعدم تسرب وجود عينة خاصة من رسائل التكرار.
- حفظ الملف والنسخة والنتيجة مع تعويض فشل التخزين قبل اعتماد أي سجل.
- الاسترجاع من النسخ الاحتياطية، سجل مراجعة غير قابل لتعديل المستخدم، وتصحيح البيانات بالمراجعة.
- عينات اختبار مع تغيير متعمد للرقم، واختلاف مشروعين، وربط FTDNA/YFull بإثبات مشروع.
- اختبار دقة مستقل بمراجع SNP مؤكدة ومنع تسرب العينة أو أقاربها القريبين بين التدريب والاختبار؛ فصل النتائج حسب اللوحة والفرع والتغطية. نجاح اختبارات القارئ لا يثبت دقة علمية.
